# Windows-BruteForce-Detection
PowerShell 기반 Windows 로그인 실패 분석 및 브루트포스 의심 탐지 도구, Microsoft Defender 이벤트 수집, 보완 상태 조회, HTML 그리고 JSON과 256 증적 생성을 지원합니다.

Windows 보안 이벤트 로그를 분석하여 반복 로그인 실패를 탐지하고,
Microsoft Defender 이벤트와 보안 상태를 보고서로 저장하는 PowerShell 도구입니다.

## 개발 목적

반복적인 로그인 실패를 분석하고, 보안 이벤트 수집과 증적 저장 작업을 자동화하기 위해 개발했습니다.

## 주요 기능

- Security 이벤트 4625 기반 로그인 실패 분석
- 동일 원본 IP의 시간 구간별 실패 횟수 집계
- Microsoft Defender 탐지·조치 관련 이벤트 수집
- Defender 및 Windows 방화벽 상태 조회
- 감사 정책 조회
- HTML·JSON 보고서, CSV 및 수집 이벤트 XML 저장
- 결과 파일의 SHA-256 해시 생성

## 실행 방법

### 샘플 데이터 테스트

실제 로그인 시도나 악성코드 실행 없이 탐지 로직을 확인합니다.

```PowerShell
PowerShell.exe -NoProfile -ExecutionPolicy Bypass -File ".\WinSec-PC-Check.ps1" -Demo -OutputRoot "C:\sec\WinSec-Reports"
```

## 기본 탐지 기준

동일 원본 IP에서 5분 이내 로그인 실패가 10회 이상 발생하면 브루트포스 의심으로 표시합니다.

이 기준은 초기 분석용 휴리스틱이며, 공격 확정 판정이 아닙니다.
잘못 저장된 비밀번호나 서비스 인증 오류도 반복 실패를 유발할 수 있습니다.

## 결과 확인

실행 결과 폴더의 report.html을 브라우저로 열어 확인합니다.

- report.html: 조회용 보고서
- report.json: 구조화된 분석 결과
- failed-logons.csv: 로그인 실패 내역
- events.xml: 수집된 원본 이벤트 XML - 실제 수집 시 해당 이벤트가 있을 때 생성
- audit-policy.txt: 감사 정책 조회 결과 - 실제 조회 성공 시 생성
- sha256.csv: 결과 파일 해시 목록 - 해시 목록 자체는 계산 대상에서 제외

## 범위 및 제약사항

수동 실행 시점의 로그를 분석하는 도구이며 상시 감시 서비스가 아닙니다.
자동 IP 차단, 계정 잠금, 악성코드 제거 또는 서버 격리는 수행하지 않습니다.
전체 취약점 또는 CVE 진단 도구가 아닙니다.
감사 정책, 로그 보존 기간, 접근 권한에 따라 수집 결과가 달라집니다.
수집 건수 제한에 도달하면 일부 이벤트가 누락될 수 있습니다.
탐지 결과가 0건이어도 공격이나 감염이 없다고 단정할 수 없습니다.
실제 수집 로그와 보고서에는 계정명과 IP 그리고 장비 정보가 포함될 수 있습니다.

## 검증 기록

개인 PC 실행 과정에서 발견된 기본 출력 경로 처리 오류와 해시 목록 파일 접근 충돌을 수정한 뒤 정상 실행을 확인했습니다.
해시 목록 파일 접근 충돌을 수정한 뒤 정상 실행을 확인 했습니다.
Windows Server에서의 탐지 정확도와 운영 적합성은 추가 검증 대상입니다.
